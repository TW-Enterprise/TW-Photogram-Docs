# 📚 TW-Photogram — Situs Dokumentasi Resmi & Manual Book

Situs dokumentasi resmi dan generator Buku Panduan Lapangan (Manual Book PDF) untuk **TW-Photogram**, dibangun menggunakan [Astro](https://astro.build) dan [Starlight](https://starlight.astro.build).

- 🌐 **Situs Dokumentasi Online**: [https://tw-enterprise.github.io/TW-Photogram-Docs/](https://tw-enterprise.github.io/TW-Photogram-Docs/)
- 📖 **Download Manual Book PDF**: Otomatis dikompilasi pada setiap deploy GitHub Pages.
- 🛸 **Repositori Utama Aplikasi**: [TW-Enterprise/TW-Photogram](https://github.com/TW-Enterprise/TW-Photogram)

---

## 🛠️ Pengembangan Lokal

```bash
# 1. Pasang dependensi
pnpm install

# 2. Jalankan server pengembang luring
pnpm run dev

# 3. Kompilasi situs produksi & generator PDF
pnpm run build
```
